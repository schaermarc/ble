Adroid App to scan for Eddystone UID beacons and send the result (last two bytes of the InstanceIds and RSSI levels) periodically to the Swisscom IoT Cloud incl. the phones coordinates.

Be sure to disable the periodic upload functionality if you do not want your location to be shared all the time.
